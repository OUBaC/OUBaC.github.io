# Accessing the Repo
Below is a step-by-step guide to accessing and installing the repo.

**Note:** This is based on a Windows PC, so please use corresponding unix/linux commands where relevant.

**<u>Pre-Requisites</u>:** Ensure that your predecessor has added you to the list of contributors for the repo.

1.	Go to: https://jekyllrb.com/docs/ 
2.	Follow Steps (1) and (2) in order to install all the necessary packages etc.
3.	Go to: https://github.com/OUBaC/OUBaC.github.io 
4.	Clone the repo to your computer (via command prompt or whatever you are using)
5.	`cd` to the repo
6.	Run the command: `bundle update` to update the gems used for the site.
7.	Run the command: `bundle exec Jekyll serve` to spin up a local version of the website
8.	Browse to http://localhost:4000 to see the website (if this doesn’t work, then something has gone wrong in the above steps)
